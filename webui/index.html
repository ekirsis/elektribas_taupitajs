Sagaidāmais API formāts

Ierīce izsauc: <bāzes_URL>/YYYY-MM-DD?vat=true&resolution=60

Atbildes JSON struktūra:

{
  "prices": [
    {
      "start": "2024-01-01T00:00:00+02:00",
      "value": 50.12
    },
    {
      "start": "2024-01-01T01:00:00+02:00",
      "value": 38.50
    }
  ]
}

Prasības:

  • prices — JSON masīvs, obligāts, vismaz 1 ieraksts
  • start — ISO laikspiedols
  • value — decimālskaitlis EUR/MWh (ar PVN)
